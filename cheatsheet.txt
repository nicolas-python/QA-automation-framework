HTTP Status Codes

200 - OK
     Anfrage erfolgreich, Webseite erreichbar

301 - Moved Permanently
     Dauerhafte Weiterleitung

302 - Found
     Temporäre Weiterleitung

400 - Bad Request
     Fehlerhafte Anfrage

401 - Unauthorized
     Anmeldung erforderlich

403 - Forbidden
     Zugriff verweigert

404 - Not Found
     Seite nicht gefunden

500 - Internal Server Error
     Serverfehler

502 - Bad Gateway
     Fehler zwischen Servern

503 - Service Unavailable
     Dienst nicht verfügbar


QA Test Bewertung:

200 = PASS
400-499 = Client Fehler
500-599 = Server Fehler




                                Was alles abgefragt werden muss und warum

1. Erreichbarkeit✅
   Prüft, ob die Webseite überhaupt antwortet.
   wird geprüfen:
   - HTTP Status Code
   - 2xx = Erfolg
   - 3xx = Weiterleitung
   - 4xx = Client Fehler
   - 5xx = Server Fehler


2. Antwortzeit / Performance✅
   Eine erreichbare Webseite kann trotzdem zu langsam sein.

   Prüfen:
   - Ladezeit messen
   - Antwortzeit bewerten


3. Timeout✅
   Verhindert, dass der Test unendlich wartet.

   Prüfen:
   - Maximale Wartezeit festlegen
   - Fehler bei Zeitüberschreitung erkennen


4. HTTPS✅
   Ohne HTTPS könnten Daten theoretisch im Netzwerk mitgelesen werden.
   HTTP = Daten werden nicht verschlüsselt übertragen
   HTTPS = Daten werden verschlüsselt übertragen

   Prüfen:
   - HTTPS aktiv?
   - HTTP → HTTPS Weiterleitung
   - Weiterleitungsfehler


5. SSL/TLS Zertifikat✅
   Das Zertifikat bestätigt, dass die Webseite zu der angegebenen Domain gehört.
   Domain = Eine lesbare Adresse einer Webseite ,die Domain wird über DNS(Domain Name System) in eine IP-Adresse(Technische Adresse eines Servers oder Gerätes) umgewandelt, damit der Server gefunden werden kann.
   SSL = Secure Sockets Layer
   TLS = Transport Layer Security ---> TLS ist der moderne Nachfolger von SSL.

   Prüfen:
   - Zertifikat gültig?
   - Ablaufdatum prüfen
   - Zertifikat abgelaufen?

           https://google.com/test
            │       │          │
            │       │          └─ Pfad
            │       └──────────── Hostname
            └─────────────────── Schema
            HTTPS verwendet standardmäßig Port 443.
            HTTP verwendet standardmäßig Port 80.

            Hostname:
            Der Hostname identifiziert den Server bzw. die Domain,
            mit der die TLS-Verbindung aufgebaut wird.


6. Content Check✅
   Eine Seite kann erreichbar sein, aber falschen Inhalt anzeigen.

   Prüfen:
   - Erwarteter Text vorhanden?
   - Richtiger Titel?


               <title>Google</title>

7. Broken Links✅
   Verhindert tote Links auf Webseiten.

   Prüfen:
   - Alle Links testen
   - 404 Seiten finden

    r'href=["\'](.*?)["\'] sucht im HTML nach href-Attributen und gibt den Inhalt zwischen den Anführungszeichen zurück, also z. B. den Pfad oder die URL eines Links

    r' href= ["\'] (.*?) ["\'] '
   │      │       │       │
   │      │       │       └─ schließendes " oder '
   │      │       └───────── Inhalt des Links erfassen
   │      └───────────────── öffnendes " oder '
   └──────────────────────── href= suchen

    r(Raw String) = damit behandelt Python Backslashes im String nicht auf die normale Art. Bei Regex(modul re) ist das praktisch, weil man Suchmuster dadurch einfacher schreiben kann
    href= Das ist das HTML-Attribut, in dem ein Link gespeichert wird z.b <a href="/about">
    ["\']=Nach href= muss entweder ein doppeltes oder ein einfaches Anführungszeichen kommen.

(.*?) = () → markieren den Teil, den wir aus dem Treffer herauslesen wollen.
        . → steht für ein beliebiges Zeichen.
        * → bedeutet null oder beliebig viele dieser Zeichen.
        ? → macht die Suche „lazy“: Es wird so wenig wie möglich erfasst, bis das nächste passende Anführungszeichen gefunden wird.

        links prüfen und ausorteiren da sonst zu viele
                        ↓
                Was steht am Anfang?
               ↓
            #          → Anker → überspringen
            javascript: → JavaScript → überspringen
            mailto:     → E-Mail → überspringen
            leer        → kein Ziel → überspringen
            /abo/       → normaler relativer Link → behalten
            https://... → normale URL → behalten


8. Bilder / Dateien✅
   Prüft, ob alle Ressourcen geladen werden.

   Prüfen:
   - Bilder erreichbar?
   - CSS geladen?
   - JavaScript geladen?


9. HTML Struktur✅
   Prüft grundlegende Webseitenqualität.

   Prüfen:
   - Sprache Attribut prüfen <html lang="de">
   - Titel vorhanden/H1/H2... vorhanden
   - Grundstruktur <head>,<body>
   - Meta Informationen (kurze Beschreibung einer Webseite,bei einer professionell aufgebauten Website ist eine Meta-Description normalerweise sinnvoll und üblich)
            welche meta infos wären wichtig ?
                (Strg + U öffnet direkt den Seitenquelltext der aktuellen Webseite)

            - charset = damit Zeichen korrekt interpretiert werden
            - viewport = für vernünftige Darstellung auf mobilen Geräten
                         -->mobilegerade tun ja nein ?
            - description = Beschreibung der Seite für Suchmaschinen
            - robots = Anweisungen für Suchmaschinen-Crawler
                        index       → Seite darf in Suchmaschinen aufgenommen werden
                        noindex     → Seite soll nicht in Suchmaschinen aufgenommen werden

                        follow      → Suchmaschinen darf den Links auf der Seite folgen
                        nofollow    → Suchmaschinen soll den Links nicht folgen

            evt ?
            -og:title, og:image = Social-Media-Vorschauen
            -author = Angabe des Autors sinvolle info ?
